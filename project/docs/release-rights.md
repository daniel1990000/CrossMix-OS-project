# Release source and rights

The [distribution register](distribution-register.json) records exact source
identities, obligations and unresolved release evidence. It does not grant
permission or claim that a notification was delivered.

The [native component review](native-component-review.md) and its
[ledger](native-component-ledger.json) distinguish build tools, incorporated
recipe/IGM code, linked components, target dependencies and assets. R06 remains
open; native custody and a successful build cannot settle those terms.

Original Python, graphics and tools use the project MIT licence. Noto Sans uses
its retained OFL notice. The public host preview contains those components and
original theme data; it contains no spruce/PyUI runtime, PPSSPP executable, SDK
libraries, Sony assets or owner game data.

Spruce and PyUI retain their own noncommercial terms and attribution. The pinned
outer PyUI licence gives `chrisj951@gmail.com` for redistribution notification;
the nested main-ui licence gives `mainpyui@gmail.com` for noncommercial use,
including derivatives. Both name Christopher Jacobs and `@chrisbastion`.
The prepared [notification draft](author-notification-draft.txt) states the
intended TG5040 work, both proposed recipients and the public project/GitHub
contact for owner review. Actual delivery remains pending. Nothing has been sent. A draft,
host fixture flag or arbitrary card receipt cannot complete this obligation.

PPSSPP modifications and acceptance fixtures remain GPL-2.0-or-later in their
separate scope. A future emulator binary distribution needs the exact modified
source, submodules, notices and build information. The pinned PowerVR recipe
scripts lack an explicit licence grant, and redistribution of their code and
the SDK/runtime inputs remains unresolved. A successful private build and its
retained source archive do not establish distribution clearance.

The private RetroArch/IGM candidate has its own GPL-3.0-or-later scope and
[retained notice](../retroarch/NOTICE.md). The pinned spruce IGM source and
recipe do not supply an explicit grant in the inspected files. Keep the native
source archives, SDK inputs and engine binaries outside the original-only
public preview until their redistribution review is complete.

PortMaster's frontend licence does not license each engine, runtime or commercial
game asset. Keep per-title provenance and owner's game data separate. Apply the
same rule to fonts and other assets: a repository's top-level licence does not
automatically cover every bundled file.

The combined candidate therefore stays private with device activation disabled.
Complete the source-use notice, exact recipe/SDK/binary redistribution review and
original TG5040 acceptance before calling it a qualified device release. These
are external evidence requirements; the independent original implementation,
host tests and private build tooling can continue in the meantime.
